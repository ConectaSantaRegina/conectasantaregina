# Santa Regina Conecta (20)

Crie um site que se trata de algo que seja para o meu bairro, onde as pessoas possam ver oq temos de comercio, delivery, lojas, tbn infraestrutura de farmacias postos de saude clinicas, salão de beleza e possam ver um balcão de empregos do bairro, oq está acontecendo de novo, que tenha um lugar para propor melhorias para o bairro, ideias de ações q a comunidade se interesse doações etc um lugar onde todos pudessem se conectar para encontrar oq precisar no bairro, na aba novidades gostaria de poder ter imagens tbn além de só textos, pois as vezes serão promoções que os comerciantes vão colocar o nome do Bairro é Santa Regina   de referencia tenho esse que gosto do layout https://www.casteloparkaquatico.com.br/
